# Contributing

Suggest a useful addition or correction through an issue or pull request.

- Read the existing list and avoid duplicates. Prefer a distinct use case over adding more similar products.
- Include only AI apps, APIs, or supporting AI developer tools with a published EverList profile.
- Link to the canonical `https://everlist.dev/tools/...` profile, not a referral link or vendor homepage. Confirm it appears in the live sitemap and returns HTTP 200 with real tool content, not an error page.
- Explain why the tool is useful and disclose any affiliation. No payment buys inclusion.
- Describe actual functionality using the published profile. Do not invent capabilities, rankings, performance claims, or pricing.
- Use `- [Tool name](URL) - One factual sentence.` and end with a period. Keep entries alphabetical within their category.
- Pick the most relevant category and update the contents when adding a category.
- Report removed profiles, redirects, misleading descriptions, or obsolete tools. Maintainers may remove entries that no longer meet these criteria.

Submit tools without published profiles at https://everlist.dev first. Publication there does not guarantee inclusion here.

By contributing list text, you agree to dedicate that contribution under CC0 1.0 Universal.
