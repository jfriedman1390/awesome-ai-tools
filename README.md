# Awesome AI Tools [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A task-oriented selection of AI apps, APIs, and supporting developer tools listed on [EverList](https://everlist.dev), a software discovery platform.

Entries link to EverList profiles for more context. Selection favors a specific use case and a clear description, not popularity or paid placement. Descriptions are based on the published profiles; inclusion is not an independent product test, a security review, or an endorsement. Some tools are paid or freemium.

## APIs and developer tools

- [Arqi AI](https://everlist.dev/tools/arqi-ai-tx922) - Generate architecture blueprints and system diagrams.
- [Code By AI](https://everlist.dev/tools/code-by-ai) - Access multiple AI coding agents through one account.
- [FastGPU](https://everlist.dev/tools/fastgpu) - Compare cloud GPU rental prices and access GPU data through a REST API.
- [n8n Builder](https://everlist.dev/tools/n8n-builder-8qwqm) - Generate n8n automation workflows with AI.
- [Qodex](https://everlist.dev/tools/qodex) - Combine AI code review with API, UI, and security test runs.
- [Quady3D AI](https://everlist.dev/tools/quady3d-ai) - Generate editable 3D assets from text, images, sketches, and multi-view references.
- [SeedRouter](https://everlist.dev/tools/seedrouter) - Access multiple AI models through a single API key.
- [SkaleAgents](https://everlist.dev/tools/skaleagents) - Publish specialist agents and connect MCP from an IDE for AI DevOps workflows.
- [TokLab](https://everlist.dev/tools/toklab) - Access image, video, language, and audio models through one API key.
- [Wan API](https://everlist.dev/tools/wan-api) - Access video-generation models through an API or browser playground.
- [XCrawl](https://everlist.dev/tools/xcrawl) - Extract structured data from web pages, search results, and websites through an AI scraping API.

- [AI Image Cleaner](https://everlist.dev/tools/ai-image-cleaner) - Remove people, objects, and text from photos with background restoration.
- [AI Image Editor](https://everlist.dev/tools/ai-image-editor) - Generate images and videos with AI tools.
- [Flux 2](https://everlist.dev/tools/flux-2) - Generate and edit images from text prompts or existing visuals.

- [ProRemover](https://everlist.dev/tools/proremover) - Remove unwanted objects, people, and text from images in a browser editor.
